# 🍔 Foodie – Food Ordering Application

Foodie is a mobile food ordering application developed using React Native and Expo. It allows users to explore restaurants, search for food, add items to their cart, place orders and track their order status.

## 🚀 Features

- User Registration and Login
- Firebase Authentication
- Restaurant Listing using API
- Food Search Functionality
- Food Categories
- Restaurant Details and Menu
- Add to Cart and Remove Items
- Place Food Orders
- Order Tracking
- User Profile and Logout
- Custom Splash Screen and App Icon

## 🛠️ Technologies Used

- React Native
- Expo
- JavaScript
- TypeScript
- Firebase Authentication
- Cloud Firestore
- Axios
- OpenStreetMap API
- Git and GitHub

## ⚙️ Installation

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   `npm install`

4. Start the application:

   `npx expo start`

5. Scan the QR code using Expo Go.
